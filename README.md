# Cognizant Digital Nurture 5.0 - DeepSkilling

## Overview

This repository contains my hands-on exercises, practice programs, notes, and learning materials completed as part of the **Cognizant Digital Nurture 5.0 - Full Stack Engineer (FSE)** DeepSkilling Program.

The repository covers software design principles, data structures, SQL, testing, backend development, Angular, Git, and related technologies through practical implementations.
