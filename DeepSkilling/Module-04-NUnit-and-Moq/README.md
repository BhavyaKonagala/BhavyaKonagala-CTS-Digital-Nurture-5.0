# Module 04 - NUnit and Moq

## Overview

This module introduces the fundamentals of automated testing in .NET using the NUnit testing framework and the Moq mocking framework. It covers unit testing concepts, test organization, parameterized testing, exception testing, dependency injection, and mocking external dependencies to build reliable and maintainable applications.
