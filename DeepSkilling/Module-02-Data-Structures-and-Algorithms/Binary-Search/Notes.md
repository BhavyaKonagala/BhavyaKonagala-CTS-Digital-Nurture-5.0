# Binary Search Notes

## Definition

Binary Search is an efficient searching algorithm that works on sorted arrays by repeatedly dividing the search range into halves.

---

## Characteristics

- Requires sorted data
- Uses Divide and Conquer
- Faster than Linear Search

---

## Advantages

- Very efficient for large datasets
- Logarithmic time complexity
- Less number of comparisons

---

## Disadvantages

- Requires sorted array
- Not suitable for linked lists

---

## Time Complexity

Best Case → O(1)

Average Case → O(log n)

Worst Case → O(log n)

---

## Space Complexity

O(1)

---

## Real-World Examples

- Dictionary word search
- Phone contacts
- Searching in a sorted database
- Library catalog

---

## Key Takeaways

✔ Array must be sorted.

✔ Eliminates half of the search space in each iteration.

✔ Much faster than Linear Search for large datasets.
