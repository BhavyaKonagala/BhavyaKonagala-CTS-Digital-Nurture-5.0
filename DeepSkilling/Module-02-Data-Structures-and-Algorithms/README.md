# Module 02 - Data Structures and Algorithms

## Overview

This module covers the fundamental Data Structures and Algorithms (DSA) required to write efficient, optimized, and scalable software.

The module introduces algorithm analysis, linear data structures, searching techniques, and various sorting algorithms. These concepts form the foundation for solving programming problems and performing well in technical interviews.

---

## Topics Covered

### Analysis of Algorithms

- Introduction to Algorithms
- Time Complexity
- Space Complexity
- Big O Notation
- Best, Average and Worst Case Analysis

### Arrays

- Array Representation
- Traversal
- Searching
- Insertion
- Deletion

### Searching Algorithms

- Linear Search
- Binary Search

### Linked List

- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Traversal
- Insertion
- Deletion

### Sorting Algorithms

- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

- C#
- .NET Console Applications
- Object-Oriented Programming

After completing this module, I was able to:
