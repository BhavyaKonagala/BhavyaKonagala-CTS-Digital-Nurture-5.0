# Analysis of Algorithms Notes

## What is Algorithm Analysis?

Algorithm analysis is the process of measuring the efficiency of an algorithm.

The two main factors are:

- Time Complexity
- Space Complexity

---

## Time Complexity

Time complexity represents how the execution time changes with input size.

Common Time Complexities:

- O(1) → Constant Time
- O(log n) → Logarithmic Time
- O(n) → Linear Time
- O(n log n) → Linearithmic Time
- O(n²) → Quadratic Time
- O(2ⁿ) → Exponential Time
- O(n!) → Factorial Time

---

## Space Complexity

Space complexity measures the amount of memory used by an algorithm.

---

## Best Case

Minimum time required.

Example:

Binary Search finds the element on the first comparison.

---

## Average Case

Average running time for all possible inputs.

---

## Worst Case

Maximum time required.

Example:

Linear Search checks every element.

---

## Key Takeaways

✔ Analyze algorithm performance before implementation.

✔ Prefer lower time complexity whenever possible.

✔ Big O notation ignores constants and lower-order terms.

✔ Efficient algorithms improve software performance.
