# Analysis of Algorithms

## Objective

Understand the importance of algorithm analysis and learn how to evaluate the efficiency of algorithms using time and space complexity.

## Overview

Algorithm analysis helps determine how efficiently an algorithm performs as the input size increases.

The efficiency of an algorithm is measured using:

- Time Complexity
- Space Complexity

Big O notation is commonly used to represent the running time of an algorithm.

## Topics Covered

- Introduction to Algorithms
- Why Data Structures and Algorithms
- Time Complexity
- Space Complexity
- Big O Notation
- Best Case
- Average Case
- Worst Case

Space Complexity : O(1)
