# Linear Search

## Objective

Understand how the Linear Search algorithm works and when it should be used.

## Overview

Linear Search is the simplest searching algorithm. It checks each element one by one until the target element is found or the end of the array is reached.

## Algorithm

1. Start from the first element.
2. Compare it with the target element.
3. If it matches, return the index.
4. Otherwise, move to the next element.
5. Continue until the element is found or the array ends.

## Time Complexity

| Case | Complexity |
|------|------------|
| Best | O(1) |
| Average | O(n) |
| Worst | O(n) |

## Space Complexity

O(1)
