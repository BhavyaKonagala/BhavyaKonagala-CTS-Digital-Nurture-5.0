# Linear Search Notes

## Definition

Linear Search checks every element one by one until the required element is found.

---

## Characteristics

- Simple algorithm
- No sorting required
- Works on arrays and lists

---

## Advantages

- Easy to implement
- Works on sorted and unsorted data
- No preprocessing required

---

## Disadvantages

- Slow for large datasets
- Checks elements sequentially

---

## Time Complexity

Best Case → O(1)

Average Case → O(n)

Worst Case → O(n)

---

## Real-World Examples

- Searching a name in an unsorted attendance list
- Finding a number in an unsorted array
- Looking for a product in an unsorted inventory

---

## Key Takeaways

✔ Works on sorted and unsorted data.

✔ Simple but inefficient for large datasets.

✔ Best suited for small collections of data.
