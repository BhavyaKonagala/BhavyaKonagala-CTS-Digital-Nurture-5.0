# Module 02 Notes

## Analysis of Algorithms

Algorithm analysis helps evaluate the efficiency of an algorithm.

Important concepts:

- Time Complexity
- Space Complexity
- Big O Notation
- Best Case
- Average Case
- Worst Case

Common Complexities:

- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n²)

---

## Arrays

Arrays are linear data structures that store elements of the same type in contiguous memory locations.

Operations:

- Traversal
- Searching
- Insertion
- Deletion

---

## Searching Algorithms

### Linear Search

- Sequential search
- Works on sorted and unsorted arrays
- Time Complexity: O(n)

### Binary Search

- Requires sorted array
- Divide and Conquer approach
- Time Complexity: O(log n)

---

## Linked List

A Linked List stores elements as nodes connected through pointers.

Types:

- Singly Linked List
- Doubly Linked List
- Circular Linked List

Advantages:

- Dynamic size
- Easy insertion and deletion

---

## Sorting Algorithms

### Bubble Sort

Repeatedly swaps adjacent elements.

Time Complexity:

O(n²)

---

### Insertion Sort

Inserts each element into its correct position.

Time Complexity:

O(n²)

---

### Merge Sort

Uses Divide and Conquer.

Time Complexity:

O(n log n)

---

### Quick Sort

Uses Pivot Partitioning.

Average Time Complexity:

O(n log n)

Worst Case:

O(n²)

---

### Heap Sort

Uses Binary Heap.

Time Complexity:

O(n log n)

---

## Key Takeaways

- Arrays provide fast access.
- Linked Lists support dynamic memory allocation.
- Binary Search requires sorted data.
- Merge Sort guarantees O(n log n).
- Quick Sort performs well on average.
- Heap Sort provides consistent O(n log n) performance.
