# Merge Sort Notes

## Definition

Merge Sort is a Divide and Conquer sorting algorithm that recursively divides an array into smaller parts and merges them after sorting.

---

## Characteristics

- Divide and Conquer
- Stable sorting algorithm
- Recursive algorithm

---

## Advantages

- Very efficient for large datasets
- Guaranteed O(n log n) performance
- Stable sorting

---

## Disadvantages

- Requires extra memory
- Recursive implementation

---

## Time Complexity

Best Case → O(n log n)

Average Case → O(n log n)

Worst Case → O(n log n)

---

## Space Complexity

O(n)

---

## Real-World Examples

- External Sorting
- Database Systems
- Large File Processing
- Parallel Computing

---

## Key Takeaways

✔ Uses Divide and Conquer.

✔ Divides the array recursively.

✔ Merges sorted subarrays efficiently.

✔ Performs consistently well for large datasets.
