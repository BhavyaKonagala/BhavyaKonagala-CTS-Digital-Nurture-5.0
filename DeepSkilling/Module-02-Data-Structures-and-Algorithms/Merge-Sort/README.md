# Merge Sort

## Objective

Understand the Merge Sort algorithm and learn how it efficiently sorts data using the Divide and Conquer approach.

---

## Overview

Merge Sort divides the array into smaller halves, sorts each half recursively, and then merges the sorted halves into one sorted array.

It is one of the most efficient comparison-based sorting algorithms.

---

## Algorithm

1. Divide the array into two halves.
2. Recursively sort each half.
3. Merge the sorted halves.
4. Repeat until the entire array is sorted.

---

## Time Complexity

| Case | Complexity |
|------|------------|
| Best | O(n log n) |
| Average | O(n log n) |
| Worst | O(n log n) |

---

## Space Complexity

O(n)
