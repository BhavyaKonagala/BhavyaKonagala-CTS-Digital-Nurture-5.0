# Heap Sort Notes

## Definition

Heap Sort is a comparison-based sorting algorithm that uses a Binary Heap to sort elements.

---

## Characteristics

- Heap-based sorting
- In-place sorting
- Not stable

---

## Advantages

- Guaranteed O(n log n) time
- No extra memory required
- Efficient for large datasets

---

## Disadvantages

- More complex than Bubble or Insertion Sort
- Not stable

---

## Time Complexity

Best Case → O(n log n)

Average Case → O(n log n)

Worst Case → O(n log n)

---

## Space Complexity

O(1)

---

## Real-World Examples

- Priority Queues
- Operating System Scheduling
- Job Scheduling
- Graph Algorithms

---

## Key Takeaways

✔ Uses a Binary Heap.

✔ Provides guaranteed O(n log n) performance.

✔ Efficient for large datasets.

✔ Performs sorting in-place.
