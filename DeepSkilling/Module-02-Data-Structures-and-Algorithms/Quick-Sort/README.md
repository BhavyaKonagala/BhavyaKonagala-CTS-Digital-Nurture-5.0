# Quick Sort

## Objective

Understand the Quick Sort algorithm and learn how it sorts data efficiently using the Divide and Conquer technique.

---

## Overview

Quick Sort selects a pivot element, partitions the array into smaller and larger elements, and recursively sorts the partitions.

It is one of the fastest sorting algorithms for average-case performance.

---

## Algorithm

1. Select a pivot element.
2. Partition the array.
3. Place the pivot in its correct position.
4. Recursively sort the left and right partitions.

---

## Time Complexity

| Case | Complexity |
|------|------------|
| Best | O(n log n) |
| Average | O(n log n) |
| Worst | O(n²) |

---

## Space Complexity

O(log n)
