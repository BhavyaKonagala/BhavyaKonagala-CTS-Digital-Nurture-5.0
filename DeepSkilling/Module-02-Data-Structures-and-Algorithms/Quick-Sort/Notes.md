# Quick Sort Notes

## Definition

Quick Sort is a Divide and Conquer sorting algorithm that partitions an array around a pivot element.

---

## Characteristics

- Divide and Conquer
- Recursive algorithm
- In-place sorting
- Not stable

---

## Advantages

- Very fast in practice
- Efficient for large datasets
- Requires less extra memory than Merge Sort

---

## Disadvantages

- Worst-case time complexity is O(n²)
- Performance depends on pivot selection

---

## Time Complexity

Best Case → O(n log n)

Average Case → O(n log n)

Worst Case → O(n²)

---

## Space Complexity

O(log n)

---

## Real-World Examples

- Database sorting
- Large-scale applications
- Competitive programming

---

## Key Takeaways

✔ Uses a pivot element.

✔ Partitions the array into smaller and larger values.

✔ Fast average-case performance.

✔ One of the most widely used sorting algorithms.
