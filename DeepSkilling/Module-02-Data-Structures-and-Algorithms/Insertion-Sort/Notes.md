# Insertion Sort Notes

## Definition

Insertion Sort is a sorting algorithm that builds the final sorted array one element at a time.

---

## Characteristics

- Stable sorting algorithm
- In-place sorting
- Efficient for small datasets

---

## Advantages

- Easy to implement
- Performs well on nearly sorted arrays
- Requires no extra memory

---

## Disadvantages

- Slow for large datasets
- Inefficient compared to Merge Sort and Quick Sort

---

## Time Complexity

Best Case → O(n)

Average Case → O(n²)

Worst Case → O(n²)

---

## Space Complexity

O(1)

---

## Real-World Examples

- Sorting playing cards
- Small datasets
- Online sorting

---

## Key Takeaways

✔ Inserts one element at a time.

✔ Efficient for small or nearly sorted datasets.

✔ Stable and in-place sorting algorithm.
