# Arrays Notes

## Definition

An array is a collection of elements of the same type stored in contiguous memory locations.

---

## Characteristics

- Fixed Size
- Index starts from 0
- Fast random access
- Stores homogeneous data

---

## Advantages

- Easy traversal
- Fast element access
- Simple implementation

---

## Disadvantages

- Fixed size
- Costly insertion
- Costly deletion

---

## Common Operations

- Traversal
- Searching
- Insertion
- Deletion

---

## Time Complexity

Access → O(1)

Search → O(n)

Insert → O(n)

Delete → O(n)

---

## Real World Examples

- Student Marks
- Employee IDs
- Monthly Sales
- Product Prices

---

## Key Takeaways

✔ Arrays are best when the size is fixed.

✔ Arrays provide constant-time access using indexes.

✔ Arrays are widely used in searching and sorting algorithms.
