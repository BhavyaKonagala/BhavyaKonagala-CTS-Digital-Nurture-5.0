# Module 07 Notes

## Microservices

Microservices is an architectural style where an application is divided into small, independent services.

Each service:

- Performs a specific business function
- Can be deployed independently
- Communicates through APIs

---

## Advantages

- Independent deployment
- Better scalability
- Fault isolation
- Easier maintenance

---

## Challenges

- Service communication
- Security
- Monitoring
- Deployment complexity

---

## JWT Authentication

JWT (JSON Web Token) is used to authenticate users and secure API endpoints.

A JWT consists of:

- Header
- Payload
- Signature

---

## Authentication

Authentication verifies the identity of a user before granting access.

---

## Authorization

Authorization determines which resources an authenticated user can access.

---

## Microservices Security

Common security practices include:

- JWT Authentication
- HTTPS
- Role-Based Authorization
- API Gateway

---

## Summary

The mandatory hands-on for this module demonstrates securing an ASP.NET Core Web API using JWT Authentication, a key concept in Microservices-based applications.
