# Module 09 - Git

## Overview

This module introduces Git, a distributed version control system used to manage source code and collaborate efficiently. It covers repository creation, version tracking, branching, merging, conflict resolution, and synchronization with remote repositories hosted on GitHub.

## Hands-on Labs

### Git-HOL-1
- Install and verify Git
- Configure Git
- Initialize a local repository
- Create and commit files
- Connect to GitHub
- Push local repository to remote

### Git-HOL-2
- Create and configure `.gitignore`
- Ignore log files and folders
- Verify ignored files
- Commit `.gitignore`

### Git-HOL-3
- Create branches
- Switch between branches
- Commit changes in a branch
- Compare branches
- Merge branches
- Delete merged branches

### Git-HOL-4
- Create merge conflicts
- Resolve merge conflicts
- Perform conflict commits
- Update `.gitignore`
- Delete merged branches
- View Git history

### Git-HOL-5
- Verify repository status
- Pull latest changes from remote
- Push local commits
- Synchronize local and remote repositories
- Verify changes on GitHub

## Skills Learned

- Git installation and configuration

- Version control

- Merge conflict resolution
- Git history visualization
- Remote repository synchronization
- Repository maintenance
