# Git HOL 4 Notes

## Merge Conflict

A merge conflict occurs when the same part of a file is modified in different branches.

## Commands

Create Branch

```bash
git branch GitWork
```

Switch Branch

```bash
git checkout GitWork
```

Commit

```bash
git add .
git commit -m "Commit message"
```

Compare

```bash
git diff master GitWork
```

Merge

```bash
git merge GitWork
```

Status

```bash
git status
```

Delete Branch

```bash
git branch -d GitWork
```

## Learning Outcome

Learned to identify and resolve merge conflicts using Git.
