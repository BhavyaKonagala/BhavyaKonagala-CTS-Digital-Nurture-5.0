# Git HOL 5 Notes

## Commands

Check Status

```bash
git status
```

List Branches

```bash
git branch -a
```

Pull Latest Changes

```bash
git pull origin master
```

(Use `main` instead of `master` if your default branch is `main`.)

Push Changes

```bash
git push origin master
```

Verify

Open the GitHub repository and confirm that the latest commits are available.

## Learning Outcome

Learned how to synchronize local and remote Git repositories.
