# Git HOL 1

## Objective

Learn the basic Git commands and configure Git on a local machine.

## Topics Covered

- Git Installation
- Git Configuration
- Configure Username and Email
- Configure Default Editor
- Create Local Repository
- Add Files
- Commit Changes
- Push to Remote Repository
- Pull Changes

## Commands Used

- git --version
- git config
- git init
- git status
- git add
- git commit
- git pull
- git push

## Outcome

Successfully configured Git, initialized a repository, committed files, and synchronized the repository with a remote repository.
