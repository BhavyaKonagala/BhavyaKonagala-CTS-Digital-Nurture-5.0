# Swagger and API Testing Notes

## What is Swagger?

Swagger (OpenAPI) is a framework for designing, documenting, and testing REST APIs.

### Benefits

- Interactive API documentation
- Easy endpoint testing
- Automatic API documentation
- Improves developer productivity

---

## OpenAPI Specification

The OpenAPI Specification (OAS) defines a standard format for describing REST APIs.

---

## HTTP Methods

- GET – Retrieve data
- POST – Create data
- PUT – Update data
- DELETE – Remove data

---

## API Testing

Swagger UI allows developers to send requests and view responses directly from the browser without using external tools.
