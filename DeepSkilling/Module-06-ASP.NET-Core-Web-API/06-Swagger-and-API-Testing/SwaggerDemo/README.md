# Swagger and API Testing

## Overview

This project demonstrates how to document and test ASP.NET Core Web APIs using Swagger (OpenAPI). It provides a simple Employee Management API with CRUD operations that can be tested through the Swagger UI.

## Features

- Swagger Integration
- RESTful CRUD APIs
- Employee Management
- Interactive API Testing

## Technologies Used

- ASP.NET Core Web API
- C#
- Swagger (OpenAPI)

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/Employee | Get all employees |
| GET | /api/Employee/{id} | Get employee by ID |
| POST | /api/Employee | Add employee |
| PUT | /api/Employee/{id} | Update employee |
| DELETE | /api/Employee/{id} | Delete employee |

## Learning Outcomes

- Swagger UI
- API Documentation
- CRUD Operations
- API Testing
