# Module 06 - ASP.NET Core Web API

## Overview

This module focuses on building RESTful Web APIs using ASP.NET Core. It covers API development, CRUD operations, Entity Framework Core, SQL Server integration, Repository Pattern, Dependency Injection, JWT Authentication, SOAP & WCF concepts, Swagger documentation, and API testing.

## Objectives

- Understand ASP.NET Core Web API architecture.
- Build RESTful APIs.
- Perform CRUD operations.
- Connect APIs with SQL Server using Entity Framework Core.
- Implement Repository Pattern and Dependency Injection.
- Secure APIs using JWT Authentication.
- Learn SOAP and WCF fundamentals.
- Document and test APIs using Swagger.
