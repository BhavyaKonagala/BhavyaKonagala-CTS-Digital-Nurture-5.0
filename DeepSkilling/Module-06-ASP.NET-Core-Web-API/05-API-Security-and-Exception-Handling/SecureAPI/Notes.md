# API Security and Exception Handling

## JWT Authentication

JWT (JSON Web Token) is used to securely transmit information between the client and server.

### Structure

- Header
- Payload
- Signature

---

## Authentication

Authentication verifies the identity of a user.

Example:
- Username
- Password

---

## Authorization

Authorization determines what an authenticated user is allowed to access.

---

## Middleware

Middleware processes HTTP requests before they reach the controller.

Examples:

- Authentication
- Logging
- Exception Handling

---

## Exception Handling

Custom middleware catches unexpected exceptions and returns a proper response instead of crashing the application.

---
