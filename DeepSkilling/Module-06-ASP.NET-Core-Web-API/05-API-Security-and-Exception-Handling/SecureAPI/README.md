# API Security and Exception Handling

## Overview

This project demonstrates API security using JWT authentication and exception handling through custom middleware.

## Features

- JWT Authentication
- Authorization
- Secure API Endpoints
- Custom Exception Middleware
- Swagger Testing

## Technologies

- ASP.NET Core Web API
- JWT Bearer Authentication
- C#
- Swagger

## API Endpoints

POST /api/Auth/login

GET /api/Auth/profile (Authorized Users Only)

## Learning Outcomes

- JWT Authentication
- Authorization
- Middleware
- Exception Handling
- Secure APIs
