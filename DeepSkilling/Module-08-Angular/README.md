# Module 08 – Angular (v20.0)

## Overview

This module introduces Angular (v20.0) and demonstrates how to build modern Single Page Applications (SPA). It covers Angular CLI, standalone components, routing, forms, dependency injection, HTTP communication, RxJS, state management, and testing.

## Topics Covered

- Angular CLI
- Project Structure
- Standalone Components
- Data Binding
- Directives
- Pipes
- Forms
- Dependency Injection
- Services
- Routing
- HTTP Client
- RxJS
- NgRx
- Unit Testing
