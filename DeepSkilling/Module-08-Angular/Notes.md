# Module 08 Notes

## Angular

Angular is a TypeScript-based front-end framework used to build dynamic Single Page Applications.

## Features

- Component-Based Architecture
- TypeScript Support
- Dependency Injection
- Routing
- Reactive Programming
- HTTP Client
- Form Validation

## Angular CLI Commands

```bash
ng new AngularApp
ng serve
ng build
ng generate component component-name
ng generate service service-name
```

## Project Structure

- src/
- app/
- components/
- pages/
- assets/
- styles.css

## Concepts Learned

- Creating Components
- Standalone Components
- Component Communication
- Routing
- Forms
- Services
- Observables
- API Integration

## Summary

This module demonstrates building modern Angular applications using standalone components, Angular CLI, routing, services, and reusable UI components.
