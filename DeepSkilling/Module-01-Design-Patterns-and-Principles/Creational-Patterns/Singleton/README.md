# Singleton Pattern

## Objective

Understand the Singleton Design Pattern and ensure that only one object of a class is created.

## Definition

The Singleton Pattern restricts the instantiation of a class to a single object and provides a global point of access to it.

## Example

The Singleton class creates only one object.

Even if GetInstance() is called multiple times, the same object is returned.

## Advantages

- Only one object is created
- Saves memory
- Global access point
- Easy resource management

## Output

Singleton Object Created

Both objects are the same instance.
