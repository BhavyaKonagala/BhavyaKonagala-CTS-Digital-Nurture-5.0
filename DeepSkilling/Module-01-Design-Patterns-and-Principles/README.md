# Module 01 - Design Patterns and Principles

## Overview

This module introduces the fundamental software design principles and design patterns used to build maintainable, scalable, and reusable applications.

It covers the SOLID principles, Dependency Injection, and common Design Patterns that help developers solve real-world software design problems.

---

## Topics Covered

### SOLID Principles

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)
- Dependency Injection (DI)

### Creational Design Patterns

- Singleton Pattern
- Factory Method Pattern
- Builder Pattern

### Structural Design Patterns

- Adapter Pattern
- Decorator Pattern
- Proxy Pattern

### Behavioral Design Patterns

- Observer Pattern
- Strategy Pattern
- Command Pattern

### Architectural Pattern

- Model-View-Controller (MVC)

- SOLID Principles
- Design Patterns
