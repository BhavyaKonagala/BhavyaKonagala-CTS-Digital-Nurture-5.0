# MERGE, PIVOT and UNPIVOT

## Objective

Learn how to merge records between tables and transform rows into columns and columns into rows.

---

## Concepts Covered

- MERGE
- PIVOT
- UNPIVOT

---

## MERGE

MERGE combines INSERT, UPDATE and DELETE operations into a single statement.

---

## PIVOT

Converts rows into columns.

---

## UNPIVOT

Converts columns back into rows.

---

## Learning Outcomes

- Synchronize tables using MERGE
- Transform data using PIVOT
- Reverse transformed data using UNPIVOT
