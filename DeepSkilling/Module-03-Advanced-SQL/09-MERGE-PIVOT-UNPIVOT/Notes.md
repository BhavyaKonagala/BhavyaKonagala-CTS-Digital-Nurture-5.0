# MERGE, PIVOT and UNPIVOT Notes

## MERGE

Used to synchronize two tables.

Advantages

- INSERT
- UPDATE
- DELETE

using one statement.

---

## PIVOT

Transforms row values into columns.

Example

Department

↓

CSE
ECE
IT

becomes

|CSE|ECE|IT|

---

## UNPIVOT

Transforms columns back into rows.

---

## Uses

MERGE

- Data Synchronization

PIVOT

- Reports
- Dashboards

UNPIVOT

- Data Cleaning

---

## Key Points

✔ MERGE reduces multiple SQL statements.

✔ PIVOT creates summary reports.

✔ UNPIVOT reverses PIVOT.
