# Joins and Subqueries

## Objective

Understand how to retrieve related data from multiple tables using Joins and Subqueries.

---

## Topics Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Scalar Subqueries

---

## Technologies

- SQL Server
- SSMS
- VS Code SQL Extension

---

## Learning Outcomes

- Combine data from multiple tables.
- Understand join operations.
- Use nested queries.
- Improve query writing skills.
