Learn how to create and execute Stored Procedures and User Defined Functions in SQL Server.

---

## Topics Covered

- Stored Procedures
- Procedure Parameters
- Scalar Functions
- Table Valued Functions

## Learning Outcomes

- Create Stored Procedures
- Pass Parameters
- Create Scalar Functions
- Create Table-Valued Functions
- Execute reusable SQL logic
