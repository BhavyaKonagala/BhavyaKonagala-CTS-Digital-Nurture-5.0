# Views and Indexes

## Objective

Learn how to create Views and Indexes in SQL Server.

---

## Concepts Covered

- CREATE VIEW
- SELECT using View
- CREATE INDEX
- Query Optimization

---

## View

A View is a virtual table created from one or more tables.

Benefits

- Improves Security
- Simplifies Queries
- Reusable

---

## Index

An Index improves query performance by allowing SQL Server to locate records faster.

Types

- Clustered Index
- Non-Clustered Index

---

## Learning Outcome

After completing this exercise, I can

- Create Views
- Retrieve data using Views
- Create Indexes
- Improve query performance
