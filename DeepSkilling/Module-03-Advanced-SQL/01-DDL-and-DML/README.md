# DDL and DML

## Objective

Learn the basic SQL Server commands used to define database structures and manipulate data.

---

## Overview

This exercise introduces Data Definition Language (DDL) and Data Manipulation Language (DML) commands in SQL Server.

### DDL Commands

- CREATE
- ALTER
- DROP
- TRUNCATE

### DML Commands

- INSERT
- UPDATE
- DELETE
- SELECT

---

## Concepts Covered

- Create Database
- Create Table
- Modify Table
- Insert Records
- Update Records
- Delete Records
- Display Records

---

## Technologies Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

---

## Learning Outcome

After completing this exercise, you will be able to:

- Create databases and tables
- Modify existing tables
- Insert, update and delete records
- Retrieve records using SELECT
- Understand the difference between DDL and DML
