# Module 03 - Advanced SQL Using SQL Server

## Overview

This module focuses on advanced SQL Server concepts used in enterprise application development. It covers data definition and manipulation, complex querying techniques, database objects, analytical functions, exception handling, and transaction management.

The module emphasizes writing efficient SQL queries, improving database performance, and implementing reusable database components.

- INNER JOIN
- LEFT JOIN

- Scalar Subqueries

### 03. Views and Indexes

- CREATE VIEW

- Clustered Index

### 04. Window Functions
