# Window Functions

## Objective

Learn SQL Server Window Functions for ranking and analytical operations.

---

## Concepts Covered

- OVER()
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- PARTITION BY
- GROUP BY

---

## Window Functions

Window functions perform calculations across rows without grouping the result.

---

## Learning Outcomes

- Rank records
- Number rows
- Calculate averages
- Partition data
- Perform analytical queries
