# Module 05 - Entity Framework Core

## Overview

This module introduces Entity Framework Core (EF Core), Microsoft's modern Object-Relational Mapping (ORM) framework for .NET. It demonstrates how to connect .NET applications with SQL Server databases, create database models using the Code First approach, perform CRUD operations, execute LINQ queries, manage database migrations, work with entity relationships, and apply performance optimization techniques.
