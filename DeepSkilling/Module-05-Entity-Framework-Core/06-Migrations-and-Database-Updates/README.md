# EF Core Migrations and Database Updates

## Objective

Learn how to create and apply migrations using Entity Framework Core.

---

## Topics Covered

- Migrations
- Update Database
- Data Seeding
- Schema Changes

---

## Commands

```bash
dotnet ef migrations add InitialCreate

dotnet ef database update
```

---

## Learning Outcomes

- Create migrations
- Apply migrations
- Seed initial data
- Update database schema safely
