# EF Core Overview

## Objective

Understand the basics of Entity Framework Core 8 and Object Relational Mapping (ORM).

---

## Topics Covered

- What is ORM?
- EF Core Architecture
- Features of EF Core
- EF Framework vs EF Core
- EF Core 8 New Features

- Differentiate EF Framework and EF Core.
- List major EF Core features.
- Understand why EF Core is widely used in .NET applications.
