# Entity Framework Core Overview

## What is ORM?

Object Relational Mapping (ORM) is a technique that maps database tables to objects in programming languages.

Example

Customer Table

↓

Customer Class

↓

Customer Object

---

## Benefits of ORM

- Less SQL Code
- Easier Maintenance
- Better Productivity
- Type Safety
- Automatic Mapping

---

## What is Entity Framework Core?

Entity Framework Core (EF Core) is Microsoft's modern ORM framework for .NET.

It allows developers to work with databases using C# objects instead of writing SQL queries.

---

## Features of EF Core

- Cross Platform
- LINQ Queries
- Change Tracking
- Migrations
- Code First
- Database First
- Lazy Loading
- Eager Loading

---

## EF Framework vs EF Core

EF Framework

- Windows Only
- Older Technology
- .NET Framework

EF Core

- Cross Platform
- High Performance
- .NET 8+
- Lightweight
