# Relationships and Data Loading

## Objective

Learn how to create relationships between entities and retrieve related data using Entity Framework Core.

---

## Topics Covered

- One-to-Many Relationship
- Primary Key
- Foreign Key
- Navigation Properties
- Eager Loading
- Include()

---

## Learning Outcomes

- Create relationships between entities.
- Configure foreign keys.
- Retrieve related data using Include().
- Understand navigation properties.
