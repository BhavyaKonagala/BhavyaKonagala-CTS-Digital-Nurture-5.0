# CRUD Operations using EF Core

## Objective

Learn how to perform Create, Read, Update, and Delete operations using Entity Framework Core.

---

## Topics Covered

- Insert Records
- Retrieve Records
- Update Records
- Delete Records
- SaveChanges()

---

## Learning Outcomes

- Add records to the database.
- Retrieve records using LINQ.
- Update existing records.
- Delete records from the database.
- Persist changes using SaveChanges().
